# 🏋️ Gold's Gym Amravati

Welcome to the official repository for the **Gold's Gym Amravati** landing page. A premium, high-impact gym website designed with a cinematic black-and-yellow theme.

🚀 **Live Demo:** [https://saranshaharwar-code.github.io/GOLD-S-GYM/](https://saranshaharwar-code.github.io/GOLD-S-GYM/)

---

## 🎨 Design Vision
This project aims to capture the raw energy and professional atmosphere of **Gold's Gym (The Mecca of Bodybuilding)**. It uses intense cinematic lighting, bold typography, and smooth animations to provide an immersive experience for potential members.

## ✨ Features

- **🎬 Full-Screen Hero**: A powerful video background featuring gym intensity with clear call-to-action buttons.
- **📱 Fully Responsive**: Optimized for desktop, tablet, and mobile devices with a custom hamburger menu.
- **🏋️ Program Showcase**: Detailed cards for Strength Training, Muscle Building, Weight Loss, and more.
- **👨‍🏫 Trainer Profiles**: Highlighted cards for expert coaches and their specializations.
- **💳 Membership Plans**: Transparent pricing tiers with a "Most Popular" highlight.
- **📍 Local Integration**: Direct links to Google Maps, WhatsApp, and phone calls.
- **🎞️ Scroll Animations**: Engaging reveal-on-scroll effects powered by high-performance CSS and JavaScript.

## 🛠️ Technology Stack

- **HTML5**: Semantic structure for SEO.
- **CSS3 (Vanilla)**: Custom design system, glassmorphism, and responsive layouts.
- **JavaScript (ES6+)**: Scroll logic, mobile navigation, and visual reveals.
- **Lucide Icons**: Clean, modern iconography.
- **Google Fonts**: Oswald (Headers) and Inter (Body).

## 📂 Project Structure

```text
├── images/             # Custom-generated high-quality assets
├── index.html          # Main landing page
├── style.css           # Premium design styles
├── script.js           # Interactive logic
└── video.mp4           # Hero background video
```

## 🚀 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/saranshaharwar-code/GOLD-S-GYM.git
   ```
2. Navigate to the project folder:
   ```bash
   cd GOLD-S-GYM
   ```
3. Open `index.html` in your choice of browser.
